# STM32 Rhythm Trainer

A rhythm training system developed using STM32.

## Features
- Tap Tempo and metronome
- Rhythm pattern generation
- Rhythm input and accuracy evaluation
- FSM-based state management
- Interrupt-based button input
- UART communication for training results

## Hardware
- STM32 Nucleo-F446RE
- SSD1306 OLED Display (I2C)
- Push Button
- Passive Buzzer

  
## Development Environment
- Language: C
- IDE: STM32CubeIDE
- Framework: STM32 HAL Driver
